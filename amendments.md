# Amendments

Investor instructions that change a Commandment or a standing decision are recorded here by the Operator, newest last, with the exact words the Investor used. This file loads with `CLAUDE.md`, is included in every worker's instructions, and is shown by `rules/lookup.py` beside the Commandments it affects. A later entry overrides earlier entries and the Commandments (Commandment 59). Commandments 6, 7, and 11 can't be overridden. The Investors may edit this file or fold entries into `CLAUDE.md` at any time.

Format for each entry (the `Affects:` line lists Commandment numbers, or `all`):

```
## YYYY-MM-DD HH:MM ET — <GitHub username> — <issue or comment link>
> <exact text of the instruction>

Affects: 37, 41
Effect: <one line on what changed, written by the Operator>
```
