Read, in this order, and nothing else until you need it: ops/run.json (this run's day number and flags), ops/state.md (goals, blockers, where things stand), ops/board.md (the task board; a runnable task is a line starting with "- [ ]").

1. Investor messages. If ops/inbox_pending exists, run python3 tools/inbox.py list: the waiting messages from the Investors, grouped by issue. Handle them before any other work. An answer that arrives after a default was taken still counts: reverse the default if you can, and say so. A message that changes a rule or a standing decision is copied verbatim into amendments.md with its date, link, and the Commandments it affects. If run.json says inbox_only is true, this is a short inbox session: handle the messages, and any quick task they ask for that fits in a few turns, then close.
